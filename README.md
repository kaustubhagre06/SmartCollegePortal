# Smart College Portal

## Project Overview
Smart College Portal is a web-based application developed for D. Y. Patil College of Engineering, Akurdi.

It provides college information, faculty details, departments, products, shopping cart and student enquiry services in one place.

## Technologies Used
- HTML
- CSS
- JavaScript
- JSON
- Local Storage
- Fetch API

## Features
1. Home Page
2. About College
3. Faculty Information
4. Department Details
5. Dynamic Product Loading
6. Shopping Cart
7. Contact Information
8. Student Enquiry Form
9. Form Validation
10. Single Page Application Navigation

## Practical Implementation
- Practical 1: HTML Structure
- Practical 2: CSS Styling
- Practical 3: JavaScript Functionality
- Practical 4: Asynchronous Data Handling
- Practical 5: Single Page Application

## How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open index.html using Live Server.
4. Explore the Smart College Portal.
